# Qatar Building Cooling

An independent engineering and economics project investigating how passive
cooling strategies can reduce cooling energy demand in Qatar buildings, and
whether they are financially worthwhile.

## Research question

How much can roof coatings, external shading, and added insulation reduce the
cooling energy demand of a typical Qatar villa, and given current electricity
tariffs, how long do they take to pay for themselves?

## Approach

1. Build a Python heat-transfer model of a simple building using real hourly
   weather data (NASA POWER).
2. Test cooling strategies in the model and measure the reduction in demand.
3. Add economics: cost, electricity savings, payback period, sensitivity.
4. (Optional) Validate the model with a small physical experiment.
